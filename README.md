# cyrcyrgo.github.io

个人前端作品集合与 GitHub Pages 站点入口。这里汇集了多个可直接在浏览器中运行的独立应用与小工具，覆盖操作系统模拟、开发工具、效率工具、音乐、绘画与游戏等类型。

## 快速开始

打开站点首页即可浏览全部项目：[https://cyrcyrgo.github.io](https://cyrcyrgo.github.io)

首页采用暗色奢华风格设计，使用液态玻璃卡片、金属光泽标题、光标追光与 3D 磁吸悬停效果；点击任意卡片即可跳转至对应项目。

## 项目一览

### 应用与系统
- **WebNT 桌面系统**（`nt/`）：浏览器中的网页操作系统，包含窗口管理、任务栏、文件管理器与小游戏。
- **多语言终端**（`mltsf/`）：集成 Python、C++、CMD 的浏览器终端环境，支持扩展包与项目管理。
- **蟒蛇 Python IDE**（`py/`）：在线运行 Python 代码，集成文件管理、编辑器与控制台。
- **KOBG AI 训练台**（`ai/`）：配置 API 后可对模型进行强化式训练、测试与知识问答。
- **LogiX API**（`logix/api/`）：Python 静态代码分析引擎，支持简单与进阶万级规则检测，快速定位代码问题。

### KZK 工具箱
一组日常实用的轻量前端工具：
- **JSON 格式化**：粘贴 JSON 后自动高亮、折叠、校验与压缩。
- **色彩工具**：取色、调色、格式转换，前端配色好帮手。
- **单位换算器**：长度、重量、温度、货币等多类单位互相转换。
- **密码生成器**：自定义长度与字符集，一键生成安全强密码。
- **便利贴**：随手记录、贴满屏幕，支持拖拽与多色便签。
- **待办清单**：简单的任务管理，添加、完成、筛选一气呵成。
- **计时器**：倒计时、秒表、番茄钟，专注工作必备。
- **打字练习**：随机文本、速度统计、错字高亮，练手速。
- **WebNT 音乐**：本地音乐播放器，支持播放列表与封面展示。
- **像素画板**：格点绘图、调色盘、导出图片，复古创作。
- **HH 画板**：自由绘图工具，画笔、橡皮、形状与保存。

### 游戏与其他
- **2048**：经典数字滑动拼图，看看你能拼到多少。
- **加密计算**：基于密钥的加密与计算工具页。
- **AI 象棋 · 五子棋**（`ai/xq/`）：配置模型接口后，AI 实时读取棋盘与你在中国象棋、五子棋中对弈，随机先手，按规则判定胜负。

## 技术特点

- 纯前端实现，无需后端即可运行。
- 响应式布局，适配桌面与移动设备。
- 统一的奢华风格导航入口，便于快速定位所有项目。
- 所有项目通过 GitHub Pages 直接部署。

## 本地预览

克隆仓库后，使用任意静态服务器预览根目录即可，例如：

```bash
python3 -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080`。
