安装与使用

  1. 下载并安装 APK如提示未知来源，请在系统设置中允许当前浏览器或文件管理器安装应用。
  2. 授予日历读写权限打开应用后点击顶部「日历权限未开启」提示，允许读取和写入日历。
  3. 配置大模型接口填写 OpenAI 兼容的 Base URL、API Key 与模型名（默认 deepseek-chat），选择思考模式，并设置默认提醒分钟数（默认 5）。
  4. 描述日程并执行输入「明天下午 3 点和张总开会 1 小时」或「把周会删掉」，实时输出结束后勾选操作，选择日历，一键执行。
  5. 随时管理日程在「已添加的日程」中可修改标题、时间、地点、备注与提醒，或直接删除；重要提醒可随时切换。
  6. 添加常用提示词在「常用提示词」中输入并勾选，之后每次发送都会自动附带，无需重复输入。

功能

OpenAI 兼容接口标准 /chat/completions，可对接 DeepSeek、Kimi、通义、OpenAI 与自建网关。
思考模式可调支持 DeepSeek、GLM、豆包：按模型自动识别并发送 thinking 参数，可强制开启或关闭思考，不支持时自动回退。
AI 改删日程用自然语言修改或删除已有日程，模型返回带 id 的 updates / deletes，执行前逐条确认。
重复日程支持「每 N 天一次、共 M 次」以及指定多个日期，自动写入 RRULE 或按日期批量创建。
常用提示词可保存多条自定义提示词并勾选启用，每次请求自动附带，与系统提示词、用户输入一起生效。
流式实时输出以 SSE 流式接收模型输出，界面实时滚动显示 JSON 或思考内容，结束后再生成可执行的操作预览。
纯 JSON 约束系统提示词强制模型只返回结构化 JSON，应用内直接解析为新增/修改/删除操作。
一键写入日历通过系统日历权限写入事件与提醒，支持选择目标日历账户与提前提醒。
多日程识别一段话可生成多个日程，逐条勾选后再写入，避免误写。
修改与删除已写入的日程可在应用内修改标题、时间、地点、备注，或删除并同步移除系统日历事件。
提醒时间可配可设置默认提前提醒（默认 5 分钟，范围 0-10080）；模型也可在 JSON 中按日程指定 reminderMinutes。
到点立即提醒可勾选「到点立即提醒」在日程开始时提醒（0 分钟），可与提前提醒、重要提醒叠加。
重要提醒开关可为日程开启重要提醒，自动追加提前 1 天与提前 1 小时的两次提醒。
密钥本地保存接口配置仅存放在本机，不联网上传、不收集任何用户数据。

说明

  • 适用 Android 12（API 31）及以上系统，安装包为自签名，安装时提示未知来源属于正常现象。
  • 接口地址填到版本号即可，例如 https://api.deepseek.com/v1，应用会自动补全 /chat/completions。
  • 需要系统日历中存在可写账户（本机日历 / Google / 厂商日历均可），只读日历会写入失败。
  • AI 修改/删除只作用于「本应用写入」的日程；发送时会把它们的 id 与时间作为上下文给模型，模型不能编造 id。
  • 重复日程中「每 N 天共 M 次」使用日历 RRULE 表达；指定多个日期会按日期分别创建事件，可在「已添加的日程」中单独管理。
  • 思考模式仅对识别到的 DeepSeek / GLM / 豆包模型发送 thinking 参数；若网关不支持会自动去掉参数重试一次。
  • 常用提示词保存在本机并随每次请求自动附带；最多保存 20 条，可随时取消勾选或删除。
  • 流式输出需要接口支持 SSE；若网关返回普通 JSON，应用会在请求结束后直接解析，不影响使用。
  • 默认提醒时间为 5 分钟，可在配置区修改（0-10080 分钟）；模型在 JSON 中给出 reminderMinutes 时以模型为准，未给出时使用该默认值。
  • 勾选「到点立即提醒」会写入 0 分钟提醒，日程开始时触发；它独立于提前提醒，可与重要提醒（提前 1 天 + 1 小时）共存。
  • 重要提醒会在日历中生成两条提醒（提前 1 天、提前 1 小时）；未开启时按提前提醒分钟数生成。
  • 模型返回内容不符合 JSON 时，可在结果卡片中查看原始返回，便于排查接口问题。
