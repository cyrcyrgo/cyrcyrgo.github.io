本地模型

模型在本机浏览器内运行（WebGPU）。首次使用经 GitHub 加速镜像下载权重并缓存到本浏览器， 之后断网也能直接打开页面离线对话，全程不经过服务器。

首次下载通过 GitHub 加速镜像（如 gh-proxy.com）获取，文件保存在本浏览器缓存中； 下载完成后即使断网也能离线对话，服务器不保留任何对话信息。
